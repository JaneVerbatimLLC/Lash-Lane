Overview
The Lash Lane repository contains the production-ready code, brand guidelines, and operational framework for a mobile lash artistry service operating across Brooklyn, New York. Designed to deliver high-end beauty services directly to clients, the repository acts as the digital and structural foundation for an independent, community-rooted micro-enterprise.

Core Components & Features
Brand Identity (Concept B):

Features the minimalist line-art face paired with the signature script typography for Lash Lane.

Implements a sophisticated color palette consisting of Cream (#FAF5EE), Charcoal (#2C2C2C), Sage (#4A6741), and Warm Gold (#C9A84C), styled using Playfair Display and DM Sans typography.

Cluster-Focused Service Menu:

Structured pricing and descriptions for signature custom lash clusters, everyday quick-set applications, and maintenance fills.

Rideshare-Optimized Logistics & Travel Zones:

Defines transparent transit pricing tiers across Brooklyn (Zone 1 Local Hub, Zone 2 Extended Brooklyn, and Zone 3 Outer Borders) designed for a mobile non-driver utilizing rideshares and public transit.

Community Support & Funding Integration:

Includes an embedded contribution and donation interface (integrated with Stripe Payment Links and peer-to-peer options like CashApp) to support independent neighborhood artistry.

Deployment & Tech Stack:

Built as a lightweight, blazing-fast single-page application optimized for instant mobile loading and seamless deployment on Vercel with automatic custom domain and SSL management.

Developed in partnership with Jane Verbatim LLC under the Plainspoken Health and Community Initiative (PHCI) micro-enterprise framework.
